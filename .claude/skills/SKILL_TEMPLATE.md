# cuOpt Skill Template (Canonical Reference)

This template defines the required structure for all cuOpt Claude Code skills. Copy this template when creating new skills and follow the section structure exactly.

See `specs/001-cuopt-skills-integration/contracts/skill-template.md` for the full canonical template.

**All skills must include**:
- Overview (target audience, what you'll learn)
- Concepts (no code, explain ideas)
- API Reference (for API skills)
- Examples (1+ runnable code sample)
- Common Patterns (tips and best practices)
- Known Limitations (cuOpt quirks, workarounds)
- Next Steps (follow-on skills)

**For examples**:
- Must include result validation (status checks, feasibility diagnostics)
- Must be standalone runnable
- Must include expected output
- 10-50 lines of code

**For Known Limitations**:
- Reference cuOpt GitHub issues or docs
- Include version information
- Document workarounds if available
