# Figure contract: `objective_panel_<model>.png` (one per model)

Regenerated by `make_objective_panel_figures.py` from the two committed CSVs alone -- no solver import
(spec FR-008, SC-001).

- One figure per model that has at least one recorded result -- not one combined cross-model figure
  (research R8: panel sizes range 10-50 objectives, runtimes range milliseconds to 500+s, a single chart
  would be unreadable on both axes).
- X-axis: that model's `objective_id`s, in the same order as its `objective_candidates/<model>.csv`.
- Y-axis: `runtime_s_median`, log scale (matches this project's established convention for wide-dynamic
  -range solve-time figures, e.g. `make_gurobi_default_figure.py`).
- Two bars per objective: cuOpt and Gurobi, using the already CVD-validated `CONFIG_COLOR` pair reused
  verbatim from `make_residual_tradeoff_figures.py`/`make_gurobi_default_figure.py` (`#4c72b0` blue =
  cuOpt, `#dd8452` orange = Gurobi) -- no new palette to validate (research R8).
- An objective whose `both_feasible` is `False` (from `benchmark_details.csv`) MUST be visually marked as
  failed (e.g. a distinct marker/annotation) rather than plotted as an ordinary bar (FR-006, mirrors
  `contracts/figure-contract.md`'s equivalent rule in feature 010).
- The model's already-published single-objective baseline (the objective matching that model's existing
  `results/<model>.json` objective reaction) is visually distinguishable from the rest of the panel (e.g.
  a distinct marker or highlighted x-tick label) -- this is the whole point of User Story 1/SC-002: letting
  a reader see at a glance whether the published number sits with the pack or is an outlier.

## Shared

- matplotlib `Agg` backend, PNG, 300 dpi, `bbox_inches="tight"` -- matches every prior figure script in
  this project.
- Regenerates byte-for-byte reproducibly from the same committed CSVs (no wall-clock, no random elements).
