# Figure contract: `gurobi_default_comparison.png`

Regenerated by `make_gurobi_default_figure.py` from `results/gurobi_default/comparison.csv`
alone — no solver import, matching this project's existing "regenerable from committed CSV"
property (spec FR-007).

- X-axis: the models, ordered by scale then `n_cols` (same order as `benchmarks/make_figure.py`).
- Y-axis: `solve_s`, log scale (same convention as this project's other solve-time figures, given
  the wide dynamic range across model scales).
- Three bars per model: cuOpt, Gurobi (deliberately-configured, `gurobi_barrier_*`), Gurobi
  (default settings, `gurobi_default_*`).
- Colors: the existing, already CVD-validated `CONFIG_COLOR` triple from
  `make_residual_tradeoff_figures.py` (`#4c72b0` blue = cuOpt, `#dd8452` orange = Gurobi
  deliberately-configured, `#c44e52` red = Gurobi default) — research R5. No hatching on either
  Gurobi bar: neither configuration here is a non-recommended/unvalidated setting (research R4),
  unlike `residual_tradeoff`'s `residual_0` hatch.
- A model whose default-settings solve failed the correctness gate (`gurobi_default_feasible` or
  `gurobi_default_obj_agree_with_cuopt` is false) MUST be visually marked as failed on the figure
  (e.g. a distinct marker or omitted bar with an annotation) rather than plotted as if it had
  passed (spec FR-003) — never silently included as a normal bar.
- Per-bar value annotation (numeric solve time), consistent with `make_figure.py`'s existing
  annotation style.
- No violation-distribution companion figure for this feature (research R4) — solve time only.
- No baked-in title/subtitle/caveat text beyond axis/legend labels and the failed-gate marking
  above — this is a data-content figure, not one that has (yet) received the full journal-PDF
  presentation treatment (research R5 / Constitution VI re-check); that remains a separate,
  explicit follow-up.
