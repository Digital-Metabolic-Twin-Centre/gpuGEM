# Figure contract: `residual_tradeoff_violations.png` / `residual_tradeoff_solvetime.png`

Both regenerated by `make_residual_tradeoff_figures.py` from `results/residual_tradeoff/
comparison.csv` alone — no solver import, matching `benchmarks/make_figure.py`'s existing
"regenerable from committed CSV" property (spec FR-007).

## `residual_tradeoff_violations.png`

- X-axis: the 5 models, ordered by scale then `n_cols` (same order as `make_figure.py`).
- Y-axis: `residual_inf`, **log scale** (research R5 — range spans ~11 orders of magnitude).
- Three bars/markers per model: `shipped_default`, `residual_0`, `gurobi`.
- `residual_0` bars use a distinct hatch pattern from the other two (visually flags "different
  category of result," not a peer configuration to pick freely from).
- Per-bar value annotation (numeric residual), consistent with `make_figure.py`'s existing
  annotation style.
- A fixed caption present on the figure itself (not only in a separate doc) stating:
  *"per_constraint_residual=0 results are shown for comparison only; they are not validated for
  correctness and are not a recommended configuration."* (spec FR-008; data-model.md's
  `non_recommendation_notice`, reproduced verbatim).
- Zero-violation values (if any) are floored to a documented small epsilon for plotting only; the
  true value (0) appears in the annotation and in `comparison.csv` unmodified (research R5).

## `residual_tradeoff_solvetime.png`

- Same X-axis/model ordering and bar grouping as the violations figure, for visual consistency
  between the two.
- Y-axis: `solve_s`, log scale (matches `make_figure.py`'s existing convention for this project's
  solve-time figures, given the same wide dynamic range across model scales).
- Same `residual_0` hatch-pattern distinction and non-recommendation caption as the violations
  figure — a reader looking at either figure alone gets the same warning.

## Shared

- matplotlib with the `Agg` backend (no display needed, consistent with `make_figure.py`).
- PNG, 300 dpi, `bbox_inches="tight"` — matches `make_figure.py`'s output settings.
- Both figures MUST regenerate byte-for-byte reproducibly from the same committed CSV (no
  wall-clock, no random elements in the plot itself), matching this project's existing
  reproducibility contract (spec `002`).
